# QA swarm artifacts

Repro files from the QA swarm runs (NeoTech/Camcraft issue 2582): agents design parts in SolidCraft and make them in a CamCraft release over the headless MCP servers.
Each brief folder holds the agent's REPORT.md, STEPS.log, the SolidCraft design (.sc) and STEP, the CamCraft project (.camproj) and posted program (.nc).
This branch holds data only; it is never merged.

- `round2-20261122/` - CamCraft v0.25.0 + SolidCraft v0.46.2, agy (gemini-4-neon-high). `verify/` holds minimal repros made while triaging.
